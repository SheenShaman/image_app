Техническое задание:
Проект: приложение для просмотра и редактирования фотографий
Технологии: Python, PyQt5, объектно-ориентированное проектирование

1. Общая идея
Приложение должно позволять пользователю:
1.	выбрать папку с изображениями
2.	увидеть список доступных графических файлов
3.	просматривать выбранное изображение
4.	применять простые эффекты (поворот, отражение, яркость, чёрно-белый фильтр)
5.	сохранять обработанные версии в подпапку Modified
6.	обрабатывать несколько файлов подряд (batch-режим)

2. Требования к интерфейсу (PyQt5)
2.1. Основное окно
Заголовок: PhotoShelf - простой редактор фото
Минимальный размер: 900x600
Структура (QHBoxLayout + QVBoxLayout):
Левая панель:
  - Кнопка "Выбрать папку"
  - Список файлов (QListWidget) - JPEG, PNG, BMP, GIF
Правая часть:
  - Область изображения (QLabel с масштабированием)
  - Панель кнопок:
    - "Поворот влево"
    - "Поворот вправо" 
    - "Зеркально по горизонтали"
    - "Ч/Б"
    - "Ярче"
    - "Темнее"

2.2. Поведение интерфейса
•	"Выбрать папку"  QFileDialog
•	Клик по файлу  отображение изображения
•	Изменение размера окна  пропорциональное масштабирование

3. Логика работы и архитектура (OOP)
3.1. Ключевые классы
ImageManager:
•	current_path: str
•	current_image
•	load(path: str)
•	rotate_left()
•	rotate_right()
•	flip_horizontal()
•	to_grayscale()
•	change_brightness(delta: int)
•	save_modified(output_dir: str)

ImageListModel:
•	scan_directory(dir_path: str)
•	get_files() -> list[str]

MainWindow (QMainWindow):
•	виджеты
•	экземпляр ImageManager
•	обработка сигналов

4. Работа с файлами
1.	Поддерживаемые форматы: .jpg, .jpeg, .png, .bmp, .gif
2.	Подпапка Modified создаётся автоматически
3.	Имя файла: originalname_modified.ext

5. Требования к коду
•	ООП: классы, инкапсуляция
•	Модули
•	Докстринги для ключевых методов

6. Задачи проекта
1.	Загрузка и отображение изображения
2.	Подключение кнопок к ImageManager
3.	Масштабирование изображения
4.	Сохранение в подпапку Modified
5.	Пакетная обработка (дополнительно)

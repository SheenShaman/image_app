# PhotoShelf

Небольшое десктоп‑приложение для просмотра и простой обработки фотографий.

## Возможности
- выбор папки с изображениями
- просмотр выбранного файла
- повороты, отражение, ч/б, яркость
- сохранение результата в подпапку `Modified`
- пакетная обработка выбранных файлов

## Технологии
- Python 3.11–3.12
- PyQt5
- Pillow

## Запуск
```bash
poetry install
poetry run python main.py
```

## Сборка в .exe (Windows)
```bat
build.bat
```
Итоговый файл `PhotoShelf.exe` появляется в `dist` (или в корне, если в `build.bat` задан `--distpath .`).

## Поддерживаемые форматы
`.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`
